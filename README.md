# Practical RIS Gain without the Pain via Randomization and Opportunistic Scheduling in 5G NR Wireless Systems: Theory and Experiments

## 📖 Overview

This repository contains all research materials, simulation codes, experimental data, reports, presentations, publications, and supporting resources developed during my M.Tech project at the **Indian Institute of Science (IISc), Bangalore**.

The project investigates practical approaches for integrating **Reconfigurable Intelligent Surfaces (RIS)** into real-world **5G NR wireless systems**. Through theoretical analysis, simulations, and experimental validation, this work demonstrates that significant RIS gains can be achieved using **randomization** and **opportunistic scheduling**, avoiding the complexity of conventional RIS optimization techniques.
